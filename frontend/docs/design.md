# 디자인 시스템

사모이로(사장님의 1분 경영회의)의 색, 글자, 모양, 움직임, 문구 기준입니다. 새 화면이나 컴포넌트를 만들 때 이 문서의 값만 씁니다.

- **원본 자료**: `design-system/사모이로_브랜드가이드.pdf`(브랜드), `design-system/사모이로_헤더버튼시안.html`(헤더·버튼, v3 채택), `design-system/사모이로_디자인리뷰.html`(리뷰 F-01~F-09), Figma `사모이로` 파일 섹션 `638:37`(PC·모바일 화면, BI-PC-06 글자·여백 규칙).
- **코드 원본**: Tailwind 토큰은 `src/styles/index.css`의 `@theme`, antd 토큰은 `src/app/providers/theme.ts`입니다. 두 파일의 값은 항상 같아야 하고, 한쪽을 바꾸면 다른 쪽도 바꿉니다.
- **값 쓰는 법**: 화면 코드에 hex 값을 직접 쓰지 않습니다. Tailwind 클래스(`bg-surface`, `text-muted`)나 CSS 변수(`var(--color-rise)`)로 씁니다.

## 1. 브랜드

- **이름**: 서울 지하철을 모두 이으면 351.5km입니다. 사모이로는 이 숫자에서 온 이름이고, 그 노선으로 이어진 서울의 사장님이 매일 아침 1분 동안 가게의 이번 주를 준비하도록 돕습니다.
- **세 가지 약속**: 이 셋은 화면 설계의 기준입니다.
  - **1분**: 길게 읽지 않아도 오늘 할 일이 보입니다.
  - **근거**: 출처와 기준 시각을 함께 보여줍니다.
  - **준비**: 읽고 끝나지 않고 체크할 일로 남깁니다.
- **심볼**: 노란 말풍선(아침의 짧은 회의) 안에 체크(오늘 준비할 일)가 있습니다. 말풍선 꼬리는 시계의 7시 방향으로, 아침 7시 브리핑을 뜻합니다. 파일은 `public/images/logo.svg`입니다.
- **로고 종류**: 기본형(심볼 + 이름 + 슬로건)을 먼저 쓰고, 자리가 좁을수록 가로형, 심볼 순으로 줄입니다. 앱 머리말에는 가로형을 씁니다.
- **로고 규정**:
  - 로고 둘레에 x(심볼 높이의 절반) 안으로는 다른 요소를 두지 않습니다.
  - 가로형은 96px 이상, 심볼은 16px 이상으로 씁니다. 더 작으면 심볼만 씁니다.
  - 비율 늘리기, 색 바꾸기, 그림자·효과, 기울이기, 다른 서체, 대비가 낮은 바탕은 금지합니다.

### 캐릭터

- **모습**: 지하철 노선 목도리를 두르고 351.5km 이름표를 단 사모예드입니다. 윙크하며 손을 흔듭니다.
- **파일**: 전신은 `public/images/mascot.png`(대시보드 상단 블록), 얼굴은 `public/images/mascot-face.png`(브리핑 화면)입니다.
- **바탕 규칙**:
  - 전신은 연노랑 바탕이나 어두운 바탕 위에 둡니다.
  - 얼굴은 흰색이라 노란 바탕이나 어두운 바탕 위에 둡니다. 흰 바탕 위에서는 `bg-primary-100` 원 안에 넣습니다.
  - 흰 바탕(몸이 안 보임)과 진한 노란 바탕(목도리가 묻힘)은 쓰지 않습니다.
- **대체 텍스트**: 제목이 뜻을 전하는 자리에서는 꾸밈 그림이므로 `alt=""`로 둡니다.

## 2. 색

노랑은 화면에서 가장 중요한 한 곳에만 씁니다. 주 버튼이나 핵심 수치가 그 자리입니다. 비율은 무채색 70, 흰 면 20, 노랑 10입니다.

| `primary-100` | `#FFE8B8` | 캐릭터 바탕                          |

어두운 화면은 Figma `BI-PC-03 · 어두운 화면` 기준으로 갈색 기운이 없는 무채색 회색입니다.

### 상태색: 서울 브랜드의 네 색

| 상태           | 원색(아이콘·점·면)          | 글자      | 배경      | 어두운 화면 글자 / 배경 | 예                  |
| -------------- | --------------------------- | --------- | --------- | ----------------------- | ------------------- |
| 성공 `success` | `#00D778` (`success-solid`) | `#007B45` | `#E0FFF1` | `#4FE3A1` / `#0F3324`   | 준비 완료, 여유     |
| 주의 `warning` | `#FFB400`                   | `#8A6100` | `#FFF6E0` | `#FFCB57` / `#332A0C`   | 재고 확인, N건 남음 |
| 위험 `danger`  | `#FF0A73`                   | `#C20053` | `#FFE0EE` | `#FF7AB0` / `#3F0F24`   | 조회 실패, 삭제     |
| 안내 `info`    | `#0082FF`                   | `#0063C2` | `#E0F0FF` | `#7ABDFF` / `#0F2A44`   | 가격 정보           |

- **원색과 글자색**: 원색은 아이콘과 면에만 씁니다. 글자에는 어둡게 낮춘 글자색을 씁니다(옅은 배경 위 5:1 이상).
- **증감색**: 한국식으로 상승은 `rise`(= danger 글자색), 하락은 `fall`(= info 글자색)입니다.
- **색만으로 구분하지 않기**: 항상 아이콘이나 낱말을 함께 씁니다.
  - 상승·하락은 둥근 삼각형 아이콘(`TbTriangleFilled` / `TbTriangleInvertedFilled`)과 "상승", "하락" 글자를 함께 씁니다.
  - 차트의 선, 점, 그라디언트도 같은 증감색을 따릅니다. 변동이 없으면 `muted`입니다.
- **분홍 배경은 오류 전용입니다 (리뷰 F-01)**:
  - '필수' 배지는 중립 태그(`#F5F1EA` 배경, `#64594B` 글자)입니다.
  - 가격 상승은 빨간 글자와 삼각형만 쓰고 분홍 배경 박스는 쓰지 않습니다.

### 서브컬러 (데이터 전용)

- **종류**: 2025 서울색 Green Aurora(`aurora-*`)와 2024 서울색 Sky Coral(`coral-*`)입니다.
- **쓰는 곳**: 진행 막대, 차트 계열(`chart-1~3`)처럼 데이터에만 씁니다. 버튼과 헤더에는 쓰지 않습니다.

## 3. 글자

### 서체

| 서체                                                     | 쓰는 곳                                                                                           | 클래스             |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------ |
| **Pretendard** (Variable, CDN `index.html`)              | 화면의 모든 글자: 제목, 본문, 버튼, 숫자                                                          | 기본값 `font-sans` |
| **전기안전체** (`public/fonts/ElectricalSafety-*.woff2`) | 로고, 워드마크, 표지 제목, 351.5km 같은 핵심 브랜드 숫자만. Bold 700은 이름, Regular 400은 슬로건 | `font-brand`       |

- **전기안전체 범위**: 화면 UI와 본문에는 쓰지 않습니다. Figma 시안의 Noto Sans KR은 자리표시용이므로 Pretendard로 바꿔 구현합니다.
- **전기안전체 라이선스**: 한국전기안전공사 저작이고 공공누리 제1유형이라 출처 표시가 이용 조건입니다. 출처는 푸터에 표시합니다. 폰트 파일 판매와 수정 재배포는 금지입니다.
- **숫자**: 가격처럼 나란히 비교하는 숫자는 고정폭 숫자(`tabular-nums`)로 씁니다.

### 글자 규칙 7단계 (BI-PC-06)

| 역할                   | 클래스             | PC 크기/줄 간격 | 모바일  | 굵기             | 쓰는 곳                           |
| ---------------------- | ------------------ | --------------- | ------- | ---------------- | --------------------------------- |
| 화면 제목              | `text-display`     | 32 / 44         | 24 / 34 | Bold             | 화면 제목, 신호 카드 수치, 가격   |
| 카드 제목              | `text-card`        | 24 / 34         | 20 / 28 | Bold             | 카드 제목                         |
| 팝업·브리핑 제목, 로고 | `text-title`       | 24 / 34         | 20 / 28 | Bold             | 팝업 제목, 브리핑 제목, 로고 이름 |
| 항목 제목              | `text-item`        | 18 / 26         | 18 / 26 | SemiBold         | 할 일, 행사 이름, 입력 항목 이름  |
| 본문                   | `text-body`        | 16 / 26         | 16 / 26 | Regular          | 설명, 입력값                      |
| 본문 강조              | `text-body-strong` | 16 / 24         | 16 / 24 | SemiBold         | 버튼, 소제목                      |
| 보조                   | `text-caption`     | 14 / 22         | 14 / 22 | Regular·SemiBold | 기준 시각, 출처, 기대 효과        |
| 꼬리표                 | `text-tag`         | 12 / 18         | 12 / 18 | Medium·SemiBold  | 배지, 태그, 그래프 축             |

- **단위**: 크기는 rem이고 줄 간격은 rem으로 함께 정의되어 있습니다. 이 밖의 크기(`text-[15px]` 등)는 만들지 않습니다.
- **줄바꿈**: 한글은 어절 단위로 줄을 바꿉니다(`word-break: keep-all`, body에 적용됨).

### 글자 크기 설정

- **단계**: 보통 ×1, 크게 ×1.125, 아주 크게 ×1.25입니다.
- **적용 방식**: `html` font-size를 바꿔 모든 rem 값이 함께 커집니다. antd 버튼·입력 높이도 `getAppTheme(dark, scale)`에서 같은 비율로 커집니다(S 36 → 40 → 45).
- **금지**: 고정 px 높이로 글자를 가두지 않습니다. 텍스트 상자는 `min-height`를 씁니다.

## 4. 모양

- **여백**: 4의 배수 단계만 씁니다. 위계가 높을수록 커집니다. 자세한 쓰임은 `screen.md`를 봅니다.
- **모서리**:

  | 크기      | 쓰는 곳               |
  | --------- | --------------------- |
  | 20        | 강조 블록, 팝업       |
  | 16        | 카드                  |
  | 12        | 안쪽 블록, 입력, 버튼 |
  | 8         | 태그, 체크박스        |
  | 알약 모양 | 배지, 칩              |

- **높이**:

  | 높이 | 쓰는 곳                  |
  | ---- | ------------------------ |
  | 24   | 배지, 태그               |
  | 36   | 칩, 작은 버튼 S          |
  | 48   | 버튼 M, 입력             |
  | 56   | 큰 버튼 L                |
  | 44   | 모바일 누르는 영역(최소) |

- **표면**: 그림자 대신 1px 테두리로 나눕니다. 그림자는 다른 표면 위에 뜨는 것(팝오버, 토스트)에만 씁니다.
- **아이콘**: react-icons의 Lucide(`react-icons/lu`) 한 세트를 씁니다. 증감 삼각형만 Tabler(`react-icons/tb`)를 씁니다.
  - 꾸밈 아이콘에는 `aria-hidden`을 붙입니다.
  - 아이콘만 있는 버튼에는 `aria-label`을 붙입니다.

## 5. 버튼 체계 (헤더·버튼 시안)

| 종류        | antd             | 규칙                                                                                     |
| ----------- | ---------------- | ---------------------------------------------------------------------------------------- |
| 주 버튼     | `type="primary"` | 화면당 하나입니다. 노란 면에 본문색 글자를 씁니다. 예: 브리핑 받기, 다시 시도, 팝업 확인 |
| 보조 버튼   | 기본             | 진한 갈색 테두리입니다. 예: 취소, 전체 추가                                              |
| 텍스트 버튼 | `type="text"`    | 카드 안의 가벼운 동작입니다                                                              |
| 삭제 확인   | `danger`         | 빨강은 삭제 확인 창에서만 씁니다. 예: 예, 삭제해요                                       |

- **크기**: L 56(글자 18, 화면 결론), M 48(글자 16, 기본), S 36(글자 14, 카드 안)입니다. 글자는 SemiBold이고 모서리는 12입니다.
- **이동은 링크입니다**: '품목 설정 ›', '공고 보기 ↗'처럼 화살표와 갈색 글자로 씁니다. 버튼 모양으로 만들지 않습니다.
- **상태는 버튼이 아닙니다**: '완료', '확인 중', '대기'는 배지로 씁니다. 누를 수 있는 것만 테두리나 배경을 가집니다.
- **눌러서 켜고 끄는 버튼**: `aria-pressed`를 씁니다. 모양과 너비는 그대로 두고 아이콘, 글자, 색이 함께 바뀝니다(담기 ↔ 담김, 도움돼요).
- **선택 표시**: 색, 체크 아이콘, 굵은 글자 세 가지를 함께 씁니다(리뷰 F-02).

## 6. 움직임

- **기본**: 150ms 안팎의 ease-out입니다. 색 변화와 누름만 움직입니다.
- **차오름**: 진행 막대가 나타날 때 1.2초 동안 차오르고, 막대 위로 잔물결이 흐릅니다(`WaveProgress`).
- **동작 줄이기**: `prefers-reduced-motion`이면 이동, 자동 넘김, 진행 막대 물결을 모두 멈춥니다. JS에서는 `usePrefersReducedMotion()`으로 확인합니다.
- **자동으로 움직이는 것**: 멈춤 버튼을 둡니다. 마우스를 올리거나 키보드로 들어오면 잠시 멈춥니다(WCAG 2.2.2).

## 7. 문구

- **말투**: 해요체이고 문장으로 끝맺습니다. 이모지, 엠대시(—), 체크 표시 목록을 쓰지 않습니다.
- **오류 문구**: 무엇이 틀렸는지와 어떻게 고치는지를 함께 적습니다. 입력이 유지되면 "입력 정보는 그대로예요"라고 알려줍니다.
- **숫자와 날짜**: 기준 시각과 출처를 붙입니다. 예: "11월 17일 오전 7시 기준 · 서울시 농수산물 가격 정보"
- **날짜**: 요일은 2026년 달력 기준입니다(리뷰 F-05).
- **안내 문구**: 같은 안내를 한 화면에서 반복하지 않습니다(리뷰 F-07).
