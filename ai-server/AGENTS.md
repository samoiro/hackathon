# Python FastAPI 담당 AI 지침

## 작업 범위
- 이 저장소의 Python 담당 범위는 `ai-server/`입니다.
- `server/`, `frontend/`, 루트 설정은 요청 없이 수정하지 않습니다.
- API 계약 변경이 필요하면 먼저 제안하고 Java 담당자와 합의합니다.

## 대회 규정
- **본선 시작 전**: 구조, 설치, 헬스체크, 테스트환경, 설계 문서, 배포 환경만 준비합니다.
- 핵심 분석·추천 기능을 사전 구현하지 않습니다.
- **본선 시작 이후에만** `docs/AI_IMPLEMENTATION_TASKS.md`에 명시된 기능을 작성합니다.
- 운영진 확인이 필요한 사전 개발 허용 범위는 사용자에게 먼저 알립니다.

## 품질
- 타입힌트와 Pydantic 모델 사용.
- LLM 결과는 파싱·검증하고 추론과 출처 확인 사실을 구분.
- API 키는 환경변수로 관리하고 절대 커밋하지 않음.
- 테스트 및 오류처리 포함, 변경 파일·검증 결과 보고.
