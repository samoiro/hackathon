# Python 담당 범위 (기획 문서)

## 서비스
사장님의 1분 경영회의: 매장 위치·업종·관심 품목을 바탕으로 주변 행사와 원가 변동 정보를 분석하고 이번 주 행동 제안을 제공합니다.

## 담당 경계
| 영역 | 담당 |
|---|---|
| 사용자 화면 | React |
| 인증, 매장정보, DB 및 외부 데이터 수집 | Spring Boot |
| 제공된 근거 데이터의 분석, 요약, 추천 생성 | Python FastAPI |

## AI 응답 원칙
1. 확정 사실과 추정/주의 신호 구분
2. 각 추천에 근거·출처·기준 시점 첨부
3. 근거가 없으면 임의의 숫자·일정·가격을 생성하지 않음
4. 운영상 조치가 가능한 문장으로 표현
5. 분석 실패 시 Java가 처리 가능한 표준 오류 반환
