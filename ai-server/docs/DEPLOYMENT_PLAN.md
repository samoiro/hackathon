# Python 배포 준비 체크리스트

## 사전 준비
- [ ] Docker 이미지가 로컬에서 빌드되는지 확인
- [ ] `GET /health`가 200을 반환하는지 확인
- [ ] Python 버전, 호스팅 서비스 및 리전 확정
- [ ] 환경변수·비밀키 관리 방식 정의
- [ ] Java가 Python 내부 URL에 접근 가능한지 네트워크 설계
- [ ] 운영진에게 사전 배포 가능 범위 확인
